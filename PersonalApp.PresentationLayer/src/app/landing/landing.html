CORE CAPABILITIES

Everything You Need in One Unified Dashboard

Four specialized modules engineered with Red & Violet glassmorphism for seamless personal growth.

💼
01 / CAREER

Job Application Pipeline

Track your job search across every lifecycle stage: Applied, Interviewing, and Offers. Record target salaries, company requirements, and interview notes in a slide-over drawer.

  • ✓ Company & salary tracking
  • ✓ Remote, hybrid & on-site badges
  • ✓ Real-time search & status filtering
💰
02 / WEALTH

Savings & Multi-Bank Buckets

Two-tier wealth manager. Organize savings into visual purpose buckets (HDFC Emergency Fund, SBI Bike Fund) with target goal progress bars and monthly grouped transaction history.

  • ✓ Bank brand auto-detection & goal progress
  • ✓ Monthly grouped history with sub-totals
  • ✓ Interactive Month-Year dropdown filter
📚
03 / HABITS

Daily Learning & Study Calendar

Master skills like C#, Angular, and Docker. Open interactive 7-day monthly calendars, click dates to tick what you studied (e.g. OOPs Polymorphism), and build study streaks.

  • ✓ Interactive 7-day monthly calendar grid
  • ✓ Date-click check-ins with glowing ✅ checkmarks
  • ✓ Consecutive daily study streaks (🔥)
⚡
04 / PRODUCTIVITY

Global Floating Daily Checklist

A persistent floating button in the bottom-right corner accessible from any page. Type your daily morning goals, tick them off with animated strikethroughs, and watch your daily progress reach 100%.

  • ✓ Accessible everywhere without losing context
  • ✓ Fast morning quick-add input bar
  • ✓ 1-click ticking with live progress meter
ENGINEERING & ARCHITECTURE

Built with Modern 3-Tier Cloud Technologies

High performance, responsive, secure, and Google-indexed architecture.

Frontend

Angular 19+

TypeScript, Standalone Components, Reactive Signals, and Glassmorphic CSS3.

Backend

ASP.NET Core 10

C# RESTful Web API, Entity Framework Core, CORS middleware, and Swagger docs.

Database

PostgreSQL (Neon)

Serverless Cloud Database with dual local Microsoft SQL Server support.

Deployment

Vercel & Render

Automated CI/CD deployment pipelines with Docker containerization.
